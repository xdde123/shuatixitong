管理系统 Android App 工程 2.0

新增：
1. 自定义桌面图标
2. Android 12+ 启动页
3. App 本地 JSON 备份/恢复
4. 全屏沉浸式 WebView
5. PDF / DOCX / TXT 题库导入（扫描版 PDF 需 OCR）
6. 在线选择题刷题，答错自动进入错题本
7. 每日学习提醒（首次设置时需要允许通知权限）

构建：Android Studio 打开本文件夹，等待 Gradle 同步后 Build > Build APK(s)。
注意：PDF 文本提取依赖首次构建下载 pdfbox-android。

=== 真正的刷题系统 3.0 新增功能 ===
PDF / DOCX / TXT 导入 -> 自动解析标准选择题 -> 生成本地题库
支持顺序刷题、随机刷题、全程计时、自动判分
答错题目自动进入原有“错题三刷”系统，并按 3 天 / 7 天复习规则管理
刷题统计自动记录答题量、正确率、用时与最近刷题记录
注意：扫描图片型 PDF 需要 OCR；自动识别结果建议人工抽查答案。
